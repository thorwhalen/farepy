# farepy

farepy – Multi-source flight search with normalized results, caching, and batch support.

### Modules

| [`base`](farepy.base.html.md#module-farepy.base)       | Normalized data model for multi-source flight search.             |
|--------------------------------------------------------------------------------|-------------------------------------------------------------------|
| [`batch`](farepy.batch.html.md#module-farepy.batch)     | Batch flight search -- cartesian combinations and file parsing.   |
| [`cache`](farepy.cache.html.md#module-farepy.cache)     | JSON file-based caching for flight search results.                |
| [`core`](farepy.core.html.md#module-farepy.core)       | Search orchestration -- the main entry point for flight searches. |
| [`sources`](farepy.sources.html.md#module-farepy.sources) | Flight data source registry.                                      |
| [`util`](farepy.util.html.md#module-farepy.util)       | Internal utilities for farepy.                                    |
