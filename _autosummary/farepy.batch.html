farepy.batch.batch_search(legs, departure_dates, *, return_dates=None, sources=None, currency='EUR', adults=1, non_stop=None, max_results=50, use_cache=True, cache_dir=None, cache_ttl_hours=24)[source]#

Run a cartesian product of legs x departure_dates x return_dates.

Each combination is searched sequentially to respect API rate limits. Caching ensures repeated combinations are not re-queried.

Parameters:

  • legs (list[str]) – List of IATA pairs, e.g. [“MRS-REK”, “CDG-KEF”]

  • departure_dates (list[str]) – List of YYYY-MM-DD dates

  • return_dates (list[str] | None) – List of YYYY-MM-DD dates (None for one-way)

  • sources (list[str] | None) – Which sources to query (None = all available)

  • currency (str) – ISO 4217 currency code

  • adults (int) – Number of adult travelers

  • non_stop (bool | None) – Direct flights only

  • max_results (int) – Max results per source per search

  • use_cache (bool) – Use cached results

  • cache_dir (str | None) – Override cache directory

  • cache_ttl_hours (float) – Cache TTL

Return type:

list[dict]

Returns:

List of SearchResult dicts, one per combination.
